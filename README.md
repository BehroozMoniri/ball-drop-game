# Ball Drop Game 🎯

A puzzle game where you sort colored balls by dragging them between columns.

## How to Play

- Drag a ball from one column to another
- You can only move the top ball of a column
- Each column can hold up to 8 balls
- Goal: Get all balls of the same color into a single column

## Features

- Three difficulty levels (Easy, Medium, Hard)
- Progress tracking with motivational messages
- Best times saved per difficulty
- Drag and drop interface

## Play Online

Open \`index.html\` in your browser to play.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Game Mechanics

- **Easy**: 4 balls per column
- **Medium**: 5 balls per column
- **Hard**: 6 balls per column
